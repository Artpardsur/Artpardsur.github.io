# Пардус — сайт-портфолио

Сайт-визитка композитора, саунд-дизайнера и программиста Артёма Лиджиева (Pardus).
Статичный сайт без сборщиков: чистые HTML/CSS/JS. Открывается даже двойным кликом по `index.html`.

## Как посмотреть локально

Просто открой `index.html` в браузере. Для полного эффекта (пульсация туманности
от музыки и перемотка треков) запусти мини-сервер и открой http://localhost:8137:

```
cd D:\pardus-portfolio
python tools/serve.py
```

## Что где править

| Что поменять | Где |
|---|---|
| Треки: названия, жанры, настроения | `data/content.js` → `tracks` |
| Проекты: описания, ссылки | `data/content.js` → `projects` |
| Звуки на падах | `data/content.js` → `sfx` |
| Контакты (добавить соцсеть) | `data/content.js` → `contacts` |
| Тексты и переводы (9 языков) | `data/i18n.js` |
| Цвета, шрифты, отступы | `css/style.css` → блок `:root` в начале |

Жанры и настроения треков я проставил автоматически по названиям и контексту проектов —
**пройдись по `data/content.js` и поправь теги там, где слышишь иначе.**
Доступные жанры: `orchestral, ambient, dark, electronic, lofi, jazz, rock`.
Настроения: `calm, sad, happy, tense, epic, cozy`. Новые добавляются в списках
`genres`/`moods` там же + названия в `data/i18n.js` (ключи `genre.*` / `mood.*`).

## Как добавить новый трек

1. Положи mp3 в `audio/music/`, например `audio/music/my-track.mp3`.
2. Добавь запись в `data/content.js` → `tracks` по образцу соседних.
3. (Необязательно) Чтобы у трека появилась форма волны — запусти `tools/build_audio.py`
   (нужны Python и ffmpeg) или просто оставь как есть: без волны трек тоже играет.

## Пасхалки

- Кнопка **♪** в подвале сайта открывает играбельное мини-пианино (клавиши A–K).
- Konami-код (↑↑↓↓←→←→BA) меняет цветовую схему сайта.

## Как опубликовать бесплатно (GitHub Pages)

Один раз:

1. Зарегистрируйся на [github.com](https://github.com) (если ещё нет аккаунта).
2. Создай новый **публичный** репозиторий с именем `<твой-логин>.github.io`
   (например `pardus4444.github.io`) — тогда сайт будет по адресу `https://<твой-логин>.github.io`.
3. В папке сайта выполни (замени `ЛОГИН` на свой):

```
cd D:\pardus-portfolio
git remote add origin https://github.com/ЛОГИН/ЛОГИН.github.io.git
git push -u origin main
```

4. На GitHub: **Settings → Pages** → в разделе Source выбери ветку `main` → Save.
   Через пару минут сайт будет жить по адресу `https://ЛОГИН.github.io`.

Каждое обновление после правок:

```
cd D:\pardus-portfolio
git add -A
git commit -m "Обновление сайта"
git push
```

Через минуту-другую изменения появятся на сайте.
