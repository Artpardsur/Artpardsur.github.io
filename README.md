# Пардус — сайт-портфолио

Сайт-визитка композитора, саунд-дизайнера и программиста Артёма Лиджиева (Pardus):
музыка и звук для видеоигр, визуальных новелл и анимации.

**Сайт:** https://artpardsur.github.io/

## Локальный редактор

Правит названия, описания, теги, картинки, ссылки и цифры статистики — без
ручного лазания по коду. У проекта есть статус («В работе», «Вышло демо»…) и два
месяца — когда начат и последняя активность: по ним работают фильтр и сортировка
«Свежие / Давние» на сайте. Вкладка «Главная» — анонс с отсчётом, последняя
публикация на itch.io, строка статуса, обновления сайта и моды.

**Запуск:** ярлык «Редактор сайта Pardus» на рабочем столе (он же
`tools/run-editor.bat`). Браузер откроется сам; окно с чёрным фоном не закрывать —
в нём работает редактор. Закрыл окно — редактор остановился.

Из терминала то же самое: `python tools/admin.py`

* редактор — http://localhost:8138/admin/
* сайт для проверки — http://localhost:8138/

Кнопка «Сохранить» пишет правки в `data/content.js` (и `data/peaks.js`, если
пересчитывалась форма волны). На сайт они попадают после `git push` — его можно
сделать прямо во вкладке «Публикация» или вручную в VS Code.

Только предпросмотр сайта, без редактора: `python tools/serve.py` → http://localhost:8137

## Где что лежит

| Файл | Что внутри |
| --- | --- |
| `data/content.js` | проекты, композиции, звуки, контакты, цифры статистики, анонс, статус, обновления, моды |
| `data/i18n.js` | переводы интерфейса (9 языков) |
| `data/peaks.js` | формы волн и длительности (генерируется) |
| `js/sound.js` | саунд-дизайн: нарисованные сцены со звуками и кассеты с декой |
| `tools/build_audio.py` | сборка аудио из исходников (нужен ffmpeg). Только новые треки: `python tools/build_audio.py --only 2026` |
| `tools/admin.py` | локальный редактор (см. выше) |

Какая папка в `Рабочий стол\Music` к какому проекту относится — в файле
`ПАПКИ — КАКАЯ К ЧЕМУ.txt` там же.
